# Виджет банковских операций

## Описание
Проект представляет собой бэкенд-часть виджета для личного кабинета клиента банка. Он подготавливает данные для отображения списка последних успешных операций: маскирует номера карт и счетов, форматирует даты, а также фильтрует и сортирует транзакции.

## Основные функции

### 1. Маскировка данных (модули `masks` и `widget`)
Эти функции обеспечивают безопасность данных клиента, скрывая часть номера карты или счета.

*   `get_mask_card_number`: Принимает номер карты и возвращает его маску в формате `XXXX XX** **** XXXX`.
*   `get_mask_account`: Принимает номер счета и возвращает его маску в формате `**XXXX` (только последние 4 цифры).
*   `mask_account_card`: Универсальная функция, которая определяет тип входных данных (карта или счет) и применяет соответствующую маску.
*   `get_date_from_string`: Преобразует строку с датой из формата ISO (например, `2024-03-11T...`) в формат `ДД.ММ.ГГГГ`.

### 2. Обработка списков и инструменты (модули `processing` и `generators`)

*   `filter_by_state` и `sort_by_date`: Фильтрация и сортировка операций.
*   `filter_by_currency`: Фильтрация транзакций по коду валюты.
*   `transaction_descriptions`: Генератор описаний операций.
*   `card_number_generator`: Генератор номеров карт в заданном диапазоне.

### 3. Декораторы (модуль `decorators`)
В проекте реализованы вспомогательные инструменты для контроля работы функций.
* Декоратор `log`: Автоматически логирует начало и результат выполнения функции, а также фиксирует возникшую ошибку. Поддерживает вывод как в консоль, так и в файл.

### 4. Работа с CSV и Excel (модуль `file_readers`)
Проект поддерживает считывание финансовых транзакций из файлов форматов CSV и Excel (`.xlsx`).
* `read_transactions_csv(file_path)` — принимает путь к CSV-файлу, считывает данные с помощью библиотеки `pandas` и возвращает список словарей с транзакциями.
* `read_transactions_xlsx(file_path)` — принимает путь к Excel-файлу, считывает данные и возвращает список словарей с транзакциями.
* При отсутствии файлов или возникновении внутренних ошибок функции безопасно возвращают пустой список `[]`.

## Примеры использования

```python
from src.widget import mask_account_card
from src.generators import card_number_generator
from src.decorators import log

# Маскировка карты
print(mask_account_card("Visa Platinum 7000792289606361")) 
# Результат: Visa Platinum 7000 79** **** 6361
```

## Качество кода и тестирование

В проекте настроен контроль качества кода с использованием стандартных линтеров и тестов.

### Инструменты
- **Pytest**: выполнение модульных тестов и проверка покрытия.
- **Black**: автоматическое форматирование кода.
- **Isort**: автоматическая сортировка импортов.
- **Flake8**: проверка соблюдения стандартов PEP 8.
- **Mypy**: статическая проверка типизации.

### Запуск тестов и покрытие
Для запуска тестов и генерации отчета о покрытии (Target: 100%):
```bash
pytest --cov=src --cov-report=html
```
*Подробный отчет доступен в папке `htmlcov/index.html`.*

### Описание тестов
- **tests/test_masks.py**: Маскирование номеров карт и счетов.
- **tests/test_widget.py**: Логика обработки входных строк и дат.
- **tests/test_processing.py**: Фильтрация по статусам и хронологическая сортировка.
- **tests/test_generators.py**: Тестирование функций фильтрации по валюте, получения описаний и генератора номеров карт.
- **tests/test_decorators.py**: Тестирование логики декоратора (успех/ошибка)
- **tests/test_file_readers.py**: Тестирование считывания финансовых транзакций из CSV- и Excel-файлов с использованием моков.

## Интерактивный интерфейс (main.py)

В модуле `main.py` реализована основная логика взаимодействия с пользователем. Программа представляет собой консольный конвейер для гибкой фильтрации, сортировки и анализа банковских транзакций, объединяющий все модули проекта (`file_readers`, `utils`, `processing`, `generators`, `widget`).

### Реализованный функционал меню:
1. **Выбор источника данных**: Пользователь может выбрать загрузку транзакций из трех разных форматов: JSON, CSV или Excel (XLSX).
2. **Фильтрация по статусу**: Интерактивный выбор состояния операции (`EXECUTED`, `CANCELED`, `PENDING`). Ввод нечувствителен к регистру (работает как `executed`, так и `EXECUTED`). При вводе некорректного статуса программа не завершает работу, а циклически предлагает повторить ввод.
3. **Сортировка по дате**: Возможность упорядочить транзакции по возрастанию или по убыванию даты.
4. **Фильтрация по валюте**: Опция вывода исключительно рублевых транзакций (`RUB`).
5. **Текстовый поиск (RegEx)**: Фильтрация по ключевому слову или фразе в описании операции (`description`) с использованием регулярных выражений (без учета регистра).
6. **Форматированный вывод**: Вывод итогового списка транзакций с автоматическим маскированием номеров карт/счетов и приведением даты к читаемому формату `ДД.ММ.ГГГГ`. При отсутствии отправителя (например, в операции «Открытие вклада») строка направления перевода автоматически адаптируется.

### Инструкция по запуску:

Для запуска интерактивной программы выполните команду в корневом каталоге проекта:
```bash
poetry run python main.py
```
